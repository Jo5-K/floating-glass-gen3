# Situação das licenças

Esta beta não define uma licença única para todo o repositório e não relicencia os recursos de terceiros.

- Os contratos/fixtures provenientes de Gen1Recomp mantêm a licença original em `tests/fixtures/GEN1RECOMP-LICENSE.md`, incluindo os termos adicionais e as atribuições exigidas.
- Recursos e referências do Kanto Rework Suite são atribuídos a Faendra e respectivos autores. A inclusão neste pacote não concede direitos adicionais sobre esses materiais.
- Pokémon, imagens e marcas relacionadas conservam os direitos de seus respectivos titulares.
- Ainda não foi escolhida uma licença geral para as contribuições originais do Floating Glass. Não interprete esta publicação como uma concessão MIT, GPL ou equivalente sobre todos os arquivos.

Consulte THIRD_PARTY_NOTICES.md para a proveniência. Qualquer definição futura de licença deve preservar as condições dos materiais já incorporados.
