# Gastly ambiental / environmental Gastly

Extracted from the locally installed G9 Battle Sprites (Gen 3) 1.5.4, https://github.com/poooooby/g9-battle-sprites-gen3 . No G9 code is shipped or loaded at runtime. No mod dependency was added.

55 front/normal frames, 75×75, preserved without repainting/resizing, packed into a transparent 600×525 sheet (8 columns, 7 rows, last cell unused). Playback: original 8 FPS. Source atlas cell: front:6:73:0:1680; numbers block shard34, y7219, 75×4125, palette row364. Pixels decoded using the source color-index format and its original palette.

Art from La Base de Sky DBK / EeveeExpo Resource Pack, Luka S.J. and the sprite project contributors; full original credits and notices preserved under docs/credits/. Pokémon IP belongs to its respective owners. No ownership of third-party art is claimed.

Transparency oscillates slowly from 20% to 75% (alpha .80 to .25), six seconds per direction, twelve seconds per cycle; independent of frame playback. This is not an opacity range of 20–75%.
