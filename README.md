# Floating Glass Gen3 — beta - 3

## Português

Muda o visual das batalhas: fundos ultrawide, arenas, câmeras e sombras animadas. Agora com visual opcional **Emerald Green & Ivory**, golpes coloridos por tipo, SELECT em **PT-BR / English / Français / Español** e correção dos sprites e arenas esticados ao trocar o formato. Os menus fora da batalha continuam nativos.

**Requer G1R 0.3.93+.** Destinado a FireRed, LeafGreen, Ruby, Sapphire e Emerald; a validação completa em jogo continua em andamento. Alguns cenários especiais e batalhas duplas mantêm partes da interface nativa.

Testado em conjunto com [G9 Battle Sprites (Gen 3)](https://github.com/poooooby/g9-battle-sprites-gen3) e [Gen 3 HD Sprites](https://github.com/poooooby/gen3-hd-sprites). Animações e sombras observadas; ainda pode haver ajustes de posicionamento. Não depende desses mods.

Importe o ZIP pelo gerenciador do G1R. O vínculo com o GitHub está incluído para verificar futuras atualizações. O “Source code (zip)” também é importável. Na batalha, pressione SELECT para configurar; o novo visual é opcional. Comandos e tipos acompanham o texto nativo e mods de tradução. Fada recebe sua cor quando fornecido por outro mod; este mod não adiciona o tipo.

## English

Changes battle presentation: ultrawide backgrounds, arenas, camera options, and animated shadows. Now includes the optional **Emerald Green & Ivory** style, type-colored move cards, **PT-BR / English / Français / Español** settings, and a fix for stretched sprites and arenas when changing the aspect ratio. Menus outside battles remain native.

**Requires G1R 0.3.93+.** Designed for FireRed, LeafGreen, Ruby, Sapphire, and Emerald; full in-game validation is ongoing. Some special scenes and double battles retain parts of the native interface.

Tested alongside [G9 Battle Sprites (Gen 3)](https://github.com/poooooby/g9-battle-sprites-gen3) and [Gen 3 HD Sprites](https://github.com/poooooby/gen3-hd-sprites). Animated sprites and shadows were observed; positioning may still need adjustment. Neither mod is required.

Import the ZIP through G1R’s mod manager. The GitHub update link is included for checking future releases. “Source code (zip)” is also importable. Press SELECT during battle to configure; the new style is optional. Commands and move types follow native text and translation mods. Fairy gets its color when provided by another mod; this mod does not add the type.
